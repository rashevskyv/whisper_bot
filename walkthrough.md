# Walkthrough: Оновлення Whisper Bot (Версія 2.4.0)

## Огляд виконаних робіт

У версії **2.4.0** додано гнучке налаштування для ввімкнення та вимкнення автоматичного завантаження й репосту відео з соцмереж (Instagram, TikTok, Pinterest через SaveAsBot/Userbot та Twitter/X/YouTube через Direct DL):

1. **Конфігурація за замовчуванням (`config.py`)**:
   - `ENABLE_VIDEO_REPOST` (за замовчуванням `True`) — глобальне налаштування для особистих чатів.
   - `ENABLE_VIDEO_REPOST_GROUPS` (за замовчуванням `True`) — глобальне налаштування за замовчуванням для груп. Дозволяє вимкнути авторепост для всіх груп одночасно у файлі `.env` (`ENABLE_VIDEO_REPOST_GROUPS=false`).
   - Ключ `'video_repost'` додано до `DEFAULT_SETTINGS` та `DEFAULT_GROUP_SETTINGS`.

2. **Перевірка налаштування в обробнику повідомлень (`bot/handlers/text.py`)**:
   - Перед відправкою запиту до черги Userbot (`USERBOT_REGEX`) або викликом прямого завантажувача yt-dlp (`DIRECT_REGEX`) перевіряється налаштування чату `settings.get('video_repost', True)`.
   - Якщо `video_repost == False`, посилання не ставиться в чергу і не завантажується, а повідомлення переходить до стандартної обробки (як звичайний текст / AI).

3. **Інтерактивна кнопка в меню налаштувань (`bot/handlers/settings.py`)**:
   - У `settings_menu` додано кнопку «🎥 Репост відео: ✅ / ❌».
   - Додано обробник callback `toggle_video_repost` для швидкого перемикання адміністраторами групи або користувачем у приваті.

4. **Команда `/video` (`bot/handlers/commands.py`)**:
   - `/video` — показує поточний статус і надає інлайн-кнопку перемикання.
   - `/video on` / `/video off` — вмикає або вимикає репост для поточного чату.
   - `/video status` — повертає статус автозавантаження відео.
   - `/video all off` / `/video all on` — **Тільки для адміністраторів бота (`ADMIN_IDS`)**: масово вмикає/вимикає авторепост для всіх зареєстрованих груп у базі даних.

5. **Тестування та валідація**:
   - Створено тестовий набір `test_video_repost.py` (8 тестів).
   - Усі 7 тестових наборів (55 тестів) успішно пройдені в паралельному режимі (`pytest -n auto --dist=loadfile`).

## Історія попередніх версій

### Версія 2.3.0 — Інтеграція OpenRouter та сучасних моделей
- Додано `OpenRouterProvider` для моделей GPT-5.6 Luna, DeepSeek V4 Flash, Gemini 3.7 Flash, Gemini 3.5 Lite, Qwen 3.7 Flash, Mistral Small 3.
- Оновлено меню моделей та ключів API.

### Версія 2.2.2 — Стабілізація Userbot та Unbuffered Logs
- Додано `no_updates=True` для запобігання помилкам `Peer id invalid` у нових супергрупах.
- Додано `export PYTHONUNBUFFERED=1` для негайного логування в systemd.

### Версія 2.2.1 — Виправлення формату голосових .oga -> .ogg
- Додано автоконвертацію розширення `.oga` до `.ogg` для OpenAI Audio API.

### Версія 2.2.0 — Керування чергою Userbot та захист від FloodWait
- Додано інтерфейс перегляду та очищення черги завдань (`queue_menu`, `/queue`, `/queue clear`).
- Додано захист від `FLOOD_WAIT` у `userbot.py`.
