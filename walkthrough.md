# Walkthrough: Оновлення Whisper Bot (Версія 2.2.0)

## Огляд виконаних робіт

У версії **2.2.0** реалізовано повноцінний інтерфейс перегляду та керування чергою завдань юзербота (`DownloadQueue`), а також захист від перевантаження Telegram API (FloodWait):

1. **Керування чергою завантажень Userbot (UI та команди)**:
   - Створено утиліту `bot/utils/queue_manager.py` з функціями:
     - `get_queue_stats()` — повертає підрахунок завдань за статусами (`pending`, `processing`, `done`, `error`, `total`).
     - `clear_pending_tasks()` — видаляє всі очікуючі та незавершені завдання.
     - `clear_all_tasks()` — повністю очищує таблицю черги.
   - Додано кнопку **«📥 Черга завдань»** у меню налаштувань (`/start` -> ⚙️ Налаштування).
   - Меню черги виводить інтерактивне повідомлення зі статистикою та кнопками:
     - `[🗑 Очистити очікуючі (N)]` — скасовує та видаляє лише завислі/очікуючі завдання;
     - `[💥 Очистити ВСІ завдання]` — повний скид черги;
     - `[🔄 Оновити]` та `[🔙 Назад]`.
   - Додано команду `/queue` (та `/queue clear` / `/queue clear_all`) для швидкого доступу через чат.

2. **Захист від Telegram FloodWait у `userbot.py`**:
   - Реалізовано перехоплення виключень `pyrogram.errors.FloodWait`.
   - При виникненні обмеження швидкості юзербот не спамить Telegram помилками і не переводить одразу завдання в статус `error`, а акуратно повертає завдання в статус `pending`, витримує точний час очікування (`sleep(wait_time + 1)`) і продовжує роботу після зняття обмеження.

3. **Синхронізація графа знань Graphify**:
   - Виконано команду `graphify update .`, оновлено індекси [graphify-out/graph.json](file:///d:/git/dev/whisper_bot2/graphify-out/graph.json) та звіт [graphify-out/GRAPH_REPORT.md](file:///d:/git/dev/whisper_bot2/graphify-out/GRAPH_REPORT.md) (393 вузли, 1009 зв'язків, 35 кластерів).

## Історія попередніх версій

### Версія 2.1.1 — Сумісність aiohttp та консистентність gpt-4o-mini
- Виправлено конфлікт `aiohttp>=3.10.0` для підтримки `SocketTimeoutError` в нових версіях `openai`.
- Закріплено `gpt-transcribe` для звуку та `gpt-4o-mini` для відповідей/чату/зображень без прихованого перемикання на `gpt-4o`.

### Версії 1.x - 2.1.0 — Базовий функціонал
- Транскрибація аудіо/відео через `gpt-transcribe` з підтримкою FFmpeg / imageio-ffmpeg.
- 30-денний retention повідомлень, приватність у групах (`shared`/`personal`), пам'ять `/remember`, `/memories`, `/forget`.
- Словник специфічних термінів `/terms`.
- Гарантовані посилання на джерела веб-пошуку та добові ліміти транскрибації.
