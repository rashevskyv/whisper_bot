# Walkthrough: Оновлення Whisper Bot (Версія 2.2.1)

## Огляд виконаних робіт

У версії **2.2.1** усунено критичну помилку `Unsupported file format oga` при транскрибації голосових повідомлень Telegram:

1. **Сумісність форматів голосових повідомлень Telegram**:
   - Telegram зберігає голосові повідомлення у форматі Opus з розширенням `.oga`.
   - OpenAI Audio API підтримує формат OGG Opus, проте очікує валідне розширення (наприклад `.ogg`, `.mp3`, `.wav`), і відхиляє файли з розширенням `.oga` кодом 400 (`Unsupported file format oga`).
   - У `bot/utils/media.py` (`download_file`) та в `bot/ai/openai_provider.py` (`transcribe`) додано автоматичне приведення розширення `.oga` / `.opus` до `.ogg`.
   - У виклику OpenAI API `audio.transcriptions.create` файл тепер передається як кортеж `(filename, file_handle)` з гарантовано підтримуваним розширенням `.ogg`.

2. **Покриття модульними тестами**:
   - Додано тести `test_openai_transcribe_oga_renamed_to_ogg` та `test_download_file_oga_mapped_to_ogg` у `test_media_ffmpeg.py`.
   - Усі 5 наборів тестів (44 тести) успішно пройдені в паралельному режимі.

3. **Синхронізація Graphify**:
   - Оновлено граф знань командою `graphify update .` (398 вузлів, 1016 зв'язків, 35 кластерів).

## Історія попередніх версій

### Версія 2.2.0 — Керування чергою Userbot та захист від FloodWait
- Додано інтерфейс перегляду та очищення черги завдань (`queue_menu`, `/queue`, `/queue clear`).
- Додано захист від `FLOOD_WAIT` у `userbot.py` (автоматична пауза без втрати завдань).

### Версія 2.1.1 — Сумісність aiohttp та консистентність gpt-4o-mini
- Виправлено вимогу `aiohttp>=3.10.0` для підтримки `SocketTimeoutError` в `openai`.
- Закріплено `gpt-transcribe` для звуку та `gpt-4o-mini` для відповідей/чату/зображень без прихованого перемикання на `gpt-4o`.
