# Walkthrough: Оновлення Whisper Bot (Версія 2.3.0)

## Огляд виконаних робіт

У версії **2.3.0** реалізовано інтеграцію з єдиним провайдером **OpenRouter** та додано підтримку найновіших розмовних моделей для чату та аналізу зображень:

1. **Нові моделі OpenRouter**:
   - 🌙 **OpenAI GPT-5.6 Luna** (`openai/gpt-5.6-luna`) — встановлено як модель за замовчуванням.
   - ⚡ **DeepSeek V4 Flash** (`deepseek/deepseek-v4-flash-0731`) — ультрашвидка та вигідна модель ($0.14/M).
   - ✨ **Google Gemini 3.7 Flash** (`google/gemini-3.7-flash`) — флагманська модель міркування.
   - 💫 **Google Gemini 3.5 Flash Lite** (`google/gemini-3.5-flash-lite`) — надшвидка модель з мінімальним латентсі.
   - 🌐 **Qwen 3.7 Flash** (`qwen/qwen3.7-flash`) — модель від Alibaba з контекстом 1M токенів.
   - 🌪 **Mistral Small 3** (`mistralai/mistral-small-24b-instruct-2501`) — європейська модель нового покоління.

2. **Провайдер `OpenRouterProvider` (`bot/ai/openrouter_provider.py`)**:
   - Реалізовано повний життєвий цикл стрімінгу відповідей (`generate_stream`).
   - Підтримка інструментів (пошук у мережі `DuckDuckGo` із додаванням посилань на джерела, створення/видалення нагадувань).
   - Мультимодальний аналіз зображень (`analyze_image`).
   - Валідація API ключів (`validate_key`).
   - Спеціалізована транскрибація залишається закріпленою за `gpt-transcribe` (OpenAI).

3. **Оновлення інтерфейсу налаштувань**:
   - **Меню моделей (`model_menu`)**: Інтерактивні кнопки з іконками для вибору нових моделей OpenRouter.
   - **Меню ключів (`keys_menu`, `save_key`)**: Підтримка введення та шифрування ключів `sk-or-v1-...` (OpenRouter), `sk-...` (OpenAI) та `AIza...` (Google).

4. **Тестування та документація**:
   - Створено тестовий набір `test_openrouter.py` (6 тестів).
   - Усі 6 тестових наборів (50 тестів) успішно пройдені в паралельному режимі.
   - Оновлено граф знань Graphify (426 вузлів, 1091 зв'язок, 36 спільнот).

## Історія попередніх версій

### Версія 2.2.2 — Стабілізація Userbot та Unbuffered Logs
- Додано `no_updates=True` для запобігання помилкам `Peer id invalid` у нових супергрупах.
- Додано `export PYTHONUNBUFFERED=1` для негайного логування в systemd.

### Версія 2.2.1 — Виправлення формату голосових .oga -> .ogg
- Додано автоконвертацію розширення `.oga` до `.ogg` для OpenAI Audio API.

### Версія 2.2.0 — Керування чергою Userbot та захист від FloodWait
- Додано інтерфейс перегляду та очищення черги завдань (`queue_menu`, `/queue`, `/queue clear`).
- Додано захист від `FLOOD_WAIT` у `userbot.py`.
