# Walkthrough: Оновлення Whisper Bot (Версія 2.2.2)

## Огляд виконаних робіт

У версії **2.2.2** реалізовано стабілізацію роботи Userbot та налаштовано негайний вивід логів у systemd:

1. **Вимкнення зайвих оновлень у Userbot (`no_updates=True`)**:
   - Pyrogram Client юзербота тепер ініціалізується з параметром `no_updates=True`.
   - Це запобігає спробам завантажувати всі вхідні оновлення з усіх супергруп, що раніше викликало помилку `ValueError: Peer id invalid: -100...` для нових 13-значних каналів Telegram.
   - Юзербот працює виключно як вихідний воркер обробки черги завантажень (`DownloadQueue`).

2. **Негайне буферизоване логування (Unbuffered Output)**:
   - Додано `export PYTHONUNBUFFERED=1` у `start.sh`.
   - Замінено системні `print` на стандартний `logger` у `bot_runner.py` для негайного відображення подій у `journalctl` та `systemctl status`.

3. **Синхронізація Graphify**:
   - Оновлено граф знань командою `graphify update .` (400 вузлів, 1018 зв'язків, 35 кластерів).

## Історія попередніх версій

### Версія 2.2.1 — Виправлення формату голосових .oga -> .ogg
- Додано автоконвертацію розширення `.oga` до `.ogg` для OpenAI Audio API.

### Версія 2.2.0 — Керування чергою Userbot та захист від FloodWait
- Додано інтерфейс перегляду та очищення черги завдань (`queue_menu`, `/queue`, `/queue clear`).
- Додано захист від `FLOOD_WAIT` у `userbot.py` (автоматична пауза без втрати завдань).
